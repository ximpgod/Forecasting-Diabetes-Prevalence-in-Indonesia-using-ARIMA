## 📌 Project Overview
Conducted a comprehensive time-series analysis to forecast the prevalence of diabetes in Indonesia using data from the WHO Global Health Observatory. This project aims to uncover historical trends and generate actionable insights for public health monitoring and strategic planning.

## 🛠️ Tools & Technologies
- **Language:** Python
- **Libraries:** Pandas, NumPy, Statsmodels, Matplotlib, Seaborn
- **Modeling:** ARIMA (AutoRegressive Integrated Moving Average)
- **Framework:** CRISP-DM (Cross-Industry Standard Process for Data Mining)

## 📊 Methodology (CRISP-DM)
This project follows the end-to-end CRISP-DM methodology:
1. **Business Understanding:** Defining the objective to forecast diabetes prevalence to aid public health policies.
2. **Data Understanding:** Exploring the WHO Global Health Observatory dataset to identify patterns and data quality.
3. **Data Preparation:** Handling missing values, transforming data into a stationary time-series format, and splitting datasets.
4. **Modeling:** Training and optimizing the ARIMA model through parameter tuning (p, d, q).
5. **Evaluation:** Assessing model performance using metrics such as RMSE (Root Mean Squared Error) or MAE (Mean Absolute Error).
6. **Deployment:** Documenting the analytical workflow and findings for future public health research integration.

## 📂 Dataset
The dataset utilized in this project is sourced from the **WHO Global Health Observatory**, focusing specifically on the diabetes prevalence metrics for Indonesia over a specified time period.
